# 课题二至课题三：己方无人机集群位姿接口规范


> **说明**：根据《挂帅任务书》要求，课题三需接收“课题二己方无人机集群位姿信息”进行态势显示。为保证双方模块顺利解耦与联调，现由课题二（中枢节点）统一定义并输出以下标准接口。（此为初稿，仅供参考）。

## 1. 接口定义

- **发送方**：课题二系统集成节点（中枢）
- **接收方**：课题三（QGC 二次开发与态势显示）
- **通信机制**：ROS 2 话题
- **Topic 名称**：`/drone_<id>/state` （多机模式下例如：`/drone_1/state`, `/drone_2/state`）
- **消息类型**：`nav_msgs/msg/Odometry`
- **坐标系**：`header.frame_id` 为 `"world"`（全局 ENU 坐标系，单位：米）

## 2. 消息字段解析

供课题三节点开发解析使用：

- **header.stamp**：当前时间戳（用于界面平滑渲染与轨迹绘制）。
- **child_frame_id**：填入该架无人机的唯一标识（例如 `"drone_1_base_link"`），用于 UI 区分多机身份。
- **pose.position.x / y / z**：己方无人机当前的全局 ENU 三维坐标。
- **pose.orientation.x / y / z / w**：己方无人机当前的四元数姿态。
- **twist.linear.x / y / z**：己方无人机当前的线速度（可选，用于 UI 显示速度矢量）。
- **twist.angular.x / y / z**：己方无人机当前的角速度。

## 3. 对接要求与扩展

1. 课题二中枢节点将高频持续广播上述话题。
2. 课题三需编写对应的 ROS 2 订阅节点，将数据提取后接入 QGC 插件进行敌我态势渲染。
3. **扩展需求**：若课题三在界面上还需要显示其他状态（如：当前电量、飞行模式、是否锁定目标），请及时向课题二提出，中枢节点可在消息中追加自定义字段。

## 4. 数据示例
```yaml
header:
  stamp: 
    sec: 1793015504
    nanosec: 281928854
  frame_id: "world"
child_frame_id: "drone_1_base_link"
pose:
  pose:
    position: {x: 10.5, y: 20.0, z: 5.0}
    orientation: {x: 0.0, y: 0.0, z: 0.707, w: 0.707}
twist:
  twist:
    linear: {x: 2.0, y: 0.0, z: 0.0}
    angular: {x: 0.0, y: 0.0, z: 0.1}
```
内容：
### 1 时间与身份标识
- **`header.stamp`**：时间戳（精确到纳秒）。UI 渲染必须依靠此时间戳对数据进行排序，以保证绘制出的轨迹和动画平滑。
- **`header.frame_id: "world"`**：参考坐标系。代表数据使用的是全局 ENU（东-北-天）坐标系。
- **`child_frame_id: "drone_1_base_link"`**：无人机的唯一身份标识。在多机集群中，据此区分是哪一架飞机（如 drone_1、drone_2）。

### 2 空间坐标（位置）
- **`pose.pose.position: {x: 10.5, y: 20.0, z: 5.0}`**：
  - **x**：向东距离（距起飞点东侧 10.5 米）
  - **y**：向北距离（距起飞点北侧 20.0 米）
  - **z**：相对高度（离地 5.0 米）

### 3 姿态信息（朝向）
- **`pose.pose.orientation: {x: 0.0, y: 0.0, z: 0.707, w: 0.707}`**：
  这是用于表示三维旋转的**四元数**。在此示例中，将其转换为欧拉角后，代表无人机的偏航角（Yaw）为 90 度，即**机头正朝向东方**。UI 可以直接根据此数据画出机头指向箭头。

### 4 运动速度
- **`twist.twist.linear: {x: 2.0, y: 0.0, z: 0.0}`**：线速度。此时无人机正以 2.0 米/秒的速度向东平飞。
- **`twist.twist.angular: {x: 0.0, y: 0.0, z: 0.1}`**：角速度。此时无人机正以 0.1 弧度/秒的速度缓慢向右偏航转向。
