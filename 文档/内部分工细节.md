# 课题二：团队分工与接口规范宪章 (V2.0)

> **说明**：本文件旨在明确课题二内部各模块的具体职责、接口边界与协作方式。所有模块开发（包含 AI 辅助生成代码）必须严格遵守本规范，严禁越界修改他人模块或接口。

## 总体系统架构
【课题三(战略)】发指令 ➔ 【系统集成(中枢)】进行状态调度与防撞 ➔ 【规划】算拦截点 ➔ 【中枢】下发坐标与动作 ➔ 【飞控桥接】转物理指令与限幅 ➔ 【无人机执行】
*(注：视觉模块作为感知源，将目标坐标同时广播给【中枢】与【规划】)*

## 一、 飞控调试模块 (Flight Control & Bridge)

### 1. 核心任务
- 负责 PX4 飞控底层的仿真环境配置（Gazebo / Isaac Sim）。
- 负责编写底层 DDS 桥接节点，将系统集成中枢下发的标准 ROS 2 指令，转换并下发给飞控。
- 接收底层飞控的实际状态（位姿、速度、电量），并向上发布给中枢和课题三。
- **核心安全兜底**：实现底层心跳检测（Watchdog）。若与中枢断联，必须触发失控保护（Failsafe）。
- **动态限幅执行**：根据中枢发来的动作指令，动态调整物理执行速度（追踪时限速，撞击时全速）。

- 发布：接口E、接口J、接口K

## 三、 路径规划模块 (Path Planning)

### 1. 核心任务
- 负责接收外部（课题一/雷达）与视觉模块的目标位置，结合动力学模型，预测目标轨迹。
- 根据课题三下发的战术指令，计算出己方无人机应当前往的**“最优拦截点”或“追踪点”**。
- **不负责**底层的物理避障与速度控制，只提供空间坐标。

### 2. 相关接口（接口具体内容请查看《课题二内部接口规范》）：
- 订阅：接口A、接口B、接口D、接口E
- 发布：接口C

### 3. 注意事项

#### 1. 中控（课题三）指令名
为防止大小写混用或拼写错误导致中枢状态机解析失败，`action` 字段的字符串**必须严格**使用以下枚举值（全大写）：
1. **`TAKEOFF`**：起飞。指令无人机解锁并升至指定安全高度。
2. **`HOVER`**：悬停。指令无人机在当前坐标原地保持不动。
3. **`RETURN`**：返航。指令无人机触发失控保护/自动返航，飞回起飞点。
4. **`TRACK`**：跟随。尚未辨明目标身份，保持常规限幅与安全距离跟飞。
5. **`INTERCEPT`**：追击。已辨明敌意，解除常规限幅，全速切内圈卡位。
6. **`ATTACK`**：攻击。终极指令，彻底解除限幅，全速直线撞击目标。
7. **`RESUME_PATROL`**：恢复执行任务。具体内容待定。

#### 2. 核心物理参数定义

| 参数名称 | 变量符号 | 典型值（待实测调整） | 物理含义与规划用途 |
| :--- | :--- | :--- | :--- |
| **最大平飞速度** | `V_max` | `6.0 m/s` | 飞机在空旷环境直线冲刺的极限速度。规划需以此计算**最早可达时间**。 |
| **巡航跟随速度** | `V_cruise` | `3.0 m/s` | 正常追踪（`TRACK`）时的稳定飞行速度。用于平滑轨迹规划。 |
| **最大加速度** | `a_max` | `2.0 m/s²` | 飞机从静止到最大速度的加速能力。规划需以此计算**刹车距离**和转弯半径。 |
| **最大偏航角速度** | `yaw_rate` | `90 deg/s` | 机头转向的最大角速度。用于计算大机动转弯时的耗时。 |
| **最小转弯半径** | `R_min` | `待定 (约 2-3m)` | 飞机在不减速情况下的最小拐弯半径。用于规划绕过障碍或包抄的弧形轨迹。 |
| **安全悬停高度** | `H_safe` | `5.0 m` | 确保飞机不撞地、不吸入下洗气流的最低安全高度。 |

#### 3. 拦截弹道计算逻辑（仅供参考！不是一定要这样实现）

在计算针对移动目标（敌机）的拦截点时，可以考虑采用以下物理逻辑：

1. **预测拦截圈**：基于敌机的当前位置与速度矢量，结合我方无人机的 `V_max`，计算出一个“我方能在多长时间内赶到”的**空间可达域**。
2. **如果目标超出 `V_max` 极限**：如果敌机速度极快，规划应输出一个“尾随追踪点”（卡在敌机运动轨迹后方），而不是一个永远追不上的预判点。
3. **刹车缓冲**：由于存在 `a_max` 和惯性，在距离目标点小于一定阈值（比如 `1.0 m`）时，规划输出的坐标不能跨越太大，必须给中枢的平滑限幅留出刹车时间。
4. **撞击提前量**：在 `ATTACK` 模式下，规划应假设无人机将以 `V_max` 直线冲刺，算出最佳撞击交点。

*(注：以上参数为当前仿真机型的初步测算值。等总负责人下发新机型模型后，系统集成会进行“阶跃响应实测”，并第一时间更新此表中的准确数值。)*
